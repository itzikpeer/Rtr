# זורקת ת'שכל – באנר לסדנה של אלינור פור שלום

| קובץ | מה זה |
|---|---|
| `index.html` | הבאנר עם קישורים לחיצים (וואטסאפ, אתר, רשתות) – לפתיחה בדפדפן או להטמעה באתר |
| `exports/banner-1080x1350.png` | גרסת תמונה לפיד אינסטגרם / פייסבוק / סטטוס בוואטסאפ (4:5) |
| `assets/` | הנשים חתוכות מהרקע (`women-cutout.png`) והפורטרט של אלינור, מהפלייר המקורי |

## לעדכן את הקישורים
בתחתית `index.html` יש אובייקט `LINKS`. כתובת שנשארת ריקה מוצגת כאייקון עמום ולא מקשרת לשום מקום (יוטיוב מוסתר).

```js
const LINKS = {
  whatsapp: "972509027969",
  website: "https://...",
  instagram: "https://www.instagram.com/...",
  facebook: "https://www.facebook.com/...",
  youtube: ""
};
```

כל כרטיס תאריך פותח וואטסאפ עם הודעה מוכנה שכבר כוללת את העיר ואת התאריך, כך שלמתעניינת נשאר רק ללחוץ "שלח".

## הקונספט – "הבמה של השחרור"
- **ויזואל:** הנשים נחתכו מהרקע הלבן של הסטודיו והועמדו על במת תיאטרון: וילונות קטיפה סגולים עם עיטור זהב, אלומת זרקור עליהן וקונפטי זהב "נזרק" באוויר. הן עומדות מול שם הסדנה, כמו שער של מגזין, ושוברות את המסגרת אל הווילונות.
- **פונטים:**
  - *Gveret Levin* (כתב יד, קרוב ללוגו המקורי) לשם ולהערות בכתב יד.
  - *Karantina* (פונט מוצק בסגנון כרזות תיאטרון) לכותרות ולתאריכים.
  - *Fredoka* (עגול וחם) לטקסט הרץ.

  הניגוד בין הפונט המוצק לכתב היד הוא המסר: מהביקורת אל הספונטניות.
- **קופי + פסיכולוגיה:** "מה יגידו?" מופיע באותיות מוצקות ונמחק בקשקוש זהב, ומעליו כתוב ביד "שיגידו!". זה הקול הפנימי שמשתתק מול העיניים של הצופה. "זאת יכולה להיות את!" עם חץ מזמין את הצופה לדמיין את עצמה בתמונה. שלוש תגיות מפרקות התנגדויות: בלי ניסיון · בלי קהל · בלי שיפוטיות.
- **אלינור:** קרדיט בסגנון כרזת תיאטרון ("בימוי והנחיה").
- **הרשמה:** התאריכים מעוצבים ככרטיסי תיאטרון "זרוקים", עם ספח מחיר (~~120~~ → 97 ₪) וחותמת "מספר המקומות מוגבל". כל כרטיס פותח וואטסאפ עם הודעה מוכנה לעיר ולתאריך.
- **תנועה (בגרסת ה-HTML):** הזרקור מתנדנד, הקונפטי מנצנץ, הקו על "מה יגידו?" נמחק מול העיניים ו"שיגידו!" קופץ, וכפתור הוואטסאפ "נושם".

## לייצא PNG מחדש
פותחים את `index.html?export=1` בחלון ברוחב 1080 וגובה 1350, ומצלמים את האלמנט `.poster`.
