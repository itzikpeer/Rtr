# זורקת ת'שכל – באנר לסדנה של אלינור פור שלום

| קובץ | מה זה |
|---|---|
| `index.html` | הבאנר עם קישורים לחיצים (וואטסאפ, אתר, רשתות) – לפתיחה בדפדפן או להטמעה באתר |
| `exports/banner-1080x1350.png` | גרסת תמונה לפיד אינסטגרם / פייסבוק / סטטוס בוואטסאפ (4:5) |
| `assets/` | התמונה הראשית והפורטרט של אלינור, חתוכים מהפלייר המקורי |

## לעדכן את הקישורים
בתחתית `index.html` יש אובייקט `LINKS`. כתובת שנשארת ריקה מוצגת כאייקון עמום ולא מקשרת לשום מקום (יוטיוב מוסתר).

```js
const LINKS = {
  whatsapp: "972509027969",
  website: "https://...",
  instagram: "https://www.instagram.com/...",
  facebook: "https://www.facebook.com/...",
  youtube: ""
};
```

כל כרטיס תאריך פותח וואטסאפ עם הודעה מוכנה שכבר כוללת את העיר ואת התאריך, כך שלמתעניינת נשאר רק ללחוץ "שלח".

## הרציונל – החלטה אחת מכל תחום
- **קופי:** "פחות לחשוב איך זה נראה. יותר להרגיש כמה זה משחרר." – משחק על שם המותג (לזרוק את השכל), והפנייה היא ישירה, בלשון נקבה יחיד.
- **פסיכולוגיה:** קודם הפחד ("חששתי שאתפדח" – ציטוט אמיתי של משתתפת), אחר כך שלוש הבטחות שמפרקות התנגדויות (לא צריך ניסיון · בלי במה ובלי קהל · קבוצה קטנה), ואחר כך מחיר עוגן (~~120~~ → 97) ומחסור (מספר המקומות מוגבל).
- **ויזואל:** סגול עמוק וזהב מהמותג. הלוגו בכתב יד בזהב, לבנדר לטקסט משני, וירוק וואטסאפ רק לכפתורי הפעולה.
- **קומפוזיציה:** תמונה ← שם ← הבטחה ← מי מנחה ← בחירת תאריך ← פעולה. סדר הקריאה עובר מרגש לאמון ואז לפעולה, והכפתורים נמצאים בתחתית, בהישג האגודל.
- **אלינור:** תכנים ותיאורים מהפלייר בלבד (במאית · שחקנית · מנחת קבוצות · 20 שנות ניסיון). לא הוספנו טענות שלא אומתו.

## לייצא PNG מחדש
פותחים את `index.html?export=1` בחלון ברוחב 1080 וגובה 1350, ומצלמים את האלמנט `.poster`.
