# זורקת ת'שכל – באנר לסדנה של אלינור פור שלום

| קובץ | מה זה |
|---|---|
| `index.html` | הבאנר עם קישורים לחיצים (וואטסאפ, אתר, רשתות) – לפתיחה בדפדפן או להטמעה באתר |
| `exports/banner-1080x1350.png` | גרסת תמונה לפיד אינסטגרם / פייסבוק / סטטוס בוואטסאפ (4:5) |
| `assets/` | התמונה (`photo.jpg`) והפורטרט של אלינור, מהפלייר המקורי |

## לעדכן את הקישורים
בתחתית `index.html` יש אובייקט `LINKS`. כתובת שנשארת ריקה מוצגת כאייקון עמום ולא מקשרת לשום מקום (יוטיוב מוסתר).

```js
const LINKS = {
  whatsapp: "972509027969",
  website: "https://...",
  instagram: "https://www.instagram.com/...",
  facebook: "https://www.facebook.com/...",
  youtube: ""
};
```

כל כרטיס תאריך פותח וואטסאפ עם הודעה מוכנה שכבר כוללת את העיר ואת התאריך, כך שלמתעניינת נשאר רק ללחוץ "שלח".

## הקונספט – עיצוב מודרני-עריכתי
- **ויזואל:** רקע סגול-לילה עם הילות צבע רכות (סגול וזהב), גרעיניות עדינה של פילם וקווים דקים. הנשים הועברו לרקע סטודיו סגול חדש עם בוקה זהב ולבנדר. הקומפוזיט כולל שחזור צבעי קצוות, "light wrap" (אור הרקע עוטף את הקצוות), התאמת צבע, צל רך וגרעיניות משותפת, כך שהן נראות מצולמות בתוכו ולא מודבקות. הסקריפט נמצא ב-`tools/composite.py`. הלוגו בזהב חוצה את קצה התמונה.
- **פונטים:**
  - *Gveret Levin* ללוגו, קרוב ללוגו המקורי.
  - *Heebo* לכל הטקסט. מודרני, נקי ועבה בכותרות.
  - *Karantina* לתאריכים ולמחיר בכרטיסים.
- **קופי + פסיכולוגיה:** "~~מה יגידו?~~ שיגידו." – הקול המבקר מופיע דהוי ונמחק בקו זהב, והתשובה מופיעה לבנה ובולטת.
- **מבנה "בנטו" (כרטיסיות):**
  - כרטיס פרימיום לאלינור (סמכות): פורטרט בטבעת זהב, תגיות תפקיד ו-"20 שנות ניסיון" בולט. לצידו ציטוט של משתתפת (הוכחה חברתית).
  - להחלפת הפורטרט: מחליפים את `assets/elinor.jpg` בתמונה ריבועית.
  - מתחתיהן שלוש תגיות שמפרקות התנגדויות.
- **הרשמה:**
  - כרטיסי התיאטרון עם ספח המחיר (~~120~~ → 97 ₪) וחותמת "מספר המקומות מוגבל".
  - כל כרטיס פותח וואטסאפ עם הודעה מוכנה.
- **תנועה (בגרסת ה-HTML):** קו המחיקה נמתח על "מה יגידו?", נקודת ה"לייב" מהבהבת וכפתור הוואטסאפ "נושם".

## לייצא PNG מחדש
פותחים את `index.html?export=1` בחלון ברוחב 1080 וגובה 1350, ומצלמים את האלמנט `.poster`.
